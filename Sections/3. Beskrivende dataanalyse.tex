I tillegg til å kutte ut rader som mangler alder (\textit{Age}), så er følgende data wrangling gjort:

\begin{itemize}
    \item Variabelen for kjønn (\textit{Sex}) er konvertert til numeriske verdier hvor menn har fått verdien 0 og kvinner har fått verdien 0.
\end{itemize}
